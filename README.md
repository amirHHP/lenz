# لنز (Lenz) — Minimalist RSS Reader & Smart Digest

**Lenz** یک فیدخوان مینیمال، مدرن و متمرکز بر آرامش ذهنی (الهام‌گرفته از Inoreader و Zendo) است که با الگوریتم رتبه‌بندی هوشمند و یادگیری تدریجی سلایق کاربر، مهم‌ترین اخبار را به بالای لیست هدایت می‌کند.

---

## ✨ ویژگی‌های کلیدی

1. **الگوریتم رتبه‌بندی و اولویت‌بندی هوشمند (Smart Importance Ranking)**:
   - حل مشکل اصلی فیدخوان‌های سنتی (دفن شدن مطالب مهم زیر انبوه اخبار سطحی).
   - رتبه‌بندی ترکیبی (امتیاز ۰ تا ۱۰۰) بر اساس:
     - هم‌پوشانی کلیدواژه‌ها با مقالات ستاره‌دار و هایلایت‌های کاربر.
     - تازگی خبر (منحنی زوال زمانی نیمه‌عمر).
     - عمق و غنای محتوا (مقالات تحلیلی در برابر لینک‌های کوتاه).
     - اعتبار و ضریب وفاداری به منبع فید.
2. **یادگیری تدریجی سلایق کاربر (Taste & Preference Learning)**:
   - با هر بار مطالعه، ستاره‌دار کردن و هایلایت جملات، بردارهای موضوعی کاربر تقویت شده و امتیاز مقالات بعدی در آن حوزه به شکل خودکار ارتقا می‌یابد.
   - دارای صفحه اختصاصی **شناخت هوشمند سلایق** جهت شفافیت کامل مدل.
3. **«امروز چه خبر؟» — خلاصه هوشمند روزانه (Today's AI Briefing)**:
   - دسته‌بندی موضوعی رویدادهای ۲۴ ساعت گذشته (هوش مصنوعی، فناوری، جهان، توسعه و...).
   - ارائه چکیده کلیدی، ۳ تیتر برتر، و توضیح «چرا اهمیت دارد» به همراه لینک مستقیم به مقالات.
   - مجهز به موتور رسمی **Google Gemini 3.8 Flash** (`@google/genai`) و سیستم فال‌بک بومی (NLP ماتریسی درون‌برنامه‌ای برای کارکرد آفلاین و بدون نیاز اجباری به کلید API).
4. **مطالعه تمام‌متن و هایلایت در متن (Full Content & Highlighting)**:
   - ستون سمت راست متن کامل و خواندنی مقاله را به کمک موتور Readability لود می‌کند (نه فقط ۲ خط خلاصه فید).
   - امکان انتخاب متن با ماوس و ثبت فوری هایلایت رنگی (زرد، سبز، آبی) به همراه یادداشت.
   - هایلایت‌ها به صورت `<mark>` در متن ثبت شده و در بخش «هایلایت‌ها و یادداشت‌ها» متمرکز می‌شوند.
5. **کلیدهای میان‌بر سریع (Keyboard Shortcuts)**:
   - `j`: خبر بعدی + علامت‌گذاری به عنوان خوانده‌شده
   - `k`: خبر قبلی
   - `s`: ستاره‌دار کردن / علاقه‌مندی
   - `m`: تغییر وضعیت خوانده‌شده / خوانده‌نشده
   - `h`: هایلایت متن انتخابی
   - `/`: جستجو در اخبار
   - `?`: راهنمای کلیدها
   - `Esc`: خروج از حالت تمام‌صفحه زِن / بستن پنجره‌ها
6. **دایرکتوری سایت‌های برتر (مانند Readly و Inoreader)**:
   - کاتالوگ آماده از معتبرترین وب‌سایت‌های ایرانی و بین‌المللی (Hacker News, TechCrunch, The Verge, Ars Technica, دیجیاتو, زومیت, OpenAI, Quanta, BBC, Nature و...).
   - سابسکرایب با ۱ کلیک و تخصیص مستقیم به پوشه‌ها.
7. **پشتیبانی از RSS دلخواه با کشف خودکار (Auto-Discovery)**:
   - وارد کردن مستقیم آدرس سایت یا آدرس فید RSS/Atom.
8. **پوشه‌بندی و دسته‌بندی (Folders)**:
   - ساخت نامحدود پوشه برای تفکیک موضوعات (فناوری، سیاسی، طراحی، هوش مصنوعی و...).
9. **حالت مطالعه زِن (Zen Mode) و پشتیبانی تم تیره/روشن**:
   - محیطی بدون حواس‌پرتی با تایپوگرافی چشم‌نواز فارسی (Vazirmatn) و انگلیسی.

---

## 🛠 پشته فنی (Tech Stack)

- **Backend**: Node.js, Express 5, TypeScript, SQLite (`better-sqlite3`), `rss-parser`, `@mozilla/readability`, `jsdom`, `@google/genai`.
- **Frontend**: React 19, TypeScript, Vite, Tailwind CSS v4, Lucide Icons, DOMPurify.
- **Testing**: Vitest, Supertest (پوشش کامل تست‌های یکپارچه و واحد).

---

## 🚀 نحوه راه‌اندازی و اجرا

```bash
# نصب پکیج‌ها
npm install

# اجرای همزمان سرور بک‌اند و محیط کلاینت
npm run dev

# اجرای تست‌ها
npm test

# بیلد نهایی نسخه پروداکشن
npm run build
```

پس از اجرای `npm run dev`:
- فرانت‌اند روی `http://localhost:3000` در دسترس است.
- سرور API روی `http://localhost:3001` اجرا می‌شود.
